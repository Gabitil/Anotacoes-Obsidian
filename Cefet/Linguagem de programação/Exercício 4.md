Java fixa os intervalos para garantir portabilidade e comportamento previsível em qualquer lugar; C++ deixa essa definição a cargo do compilador, permitindo maior desempenho e adaptação ao hardware, algo útil em arquiteturas diversas e sistemas com restrições de memória.

Deixando fixo, java garante que um programa tenha o mesmo comportamento em qualquer plataforma, mas limita a possibilidade de ajustes específicos ao hardware

Já C++ consegue adaptar os tipos para cada tipo de hardware, garantindo um maior desempenho do sistema e consegue ajustar a restrições de memorias que, por exemplo, sistemas embarcados tem.
