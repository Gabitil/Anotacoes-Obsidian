

O que é linguagem de programação:


> "Sistema de notação para descrever computações que a maquina e o humano conseguem entender."
>- **Kenneth Louden**




o que é ser computável?

- tem que dar uma resposta, ou seja, é terminável.
- tem que ser reprodutível.
- para a mesma entrada tem que ter a mesma saída.

o que é ser legível por máquinas?

- A linguagem tem que ter uma sintaxe fixa para que o computador possa ler ou analisar o programa.
- e uma semântica fixa para que o computador saiba o significado do programa executado.

o que é ser legível por humanos?

- A linguagem deve ser de fácil entendimento por humanos
- Capacidade de prover meios se suportar e impor abstrações.
